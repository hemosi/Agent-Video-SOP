# 高阶视觉叙事与机制推演总导演 Skill（Visual Proof & Generative VFX Director）

> **核心总纲：去 PPT 的“方框外壳”，保硬核知识的“推演内核”！**
> 之前测试暴露出的两个极端误区，必须同时斩断：
> - **误区 A（PPT 看板风 — 严禁）**：满屏画圆角矩形框（Panel/Card）、表格清单、顶部状态栏、把口播词抄在白卡片上——有信息但毫无美感。
> - **误区 B（鸡汤屏保风 — 严禁）**：先定一句“别怕犯错”的励志口号，东拼西凑四五个毫不相干的例子；台词在讲数据和原理，画面却在画毫不相干的“月亮下的树、夕阳下的桥、发光的河”，关键数字缩成角落里 `20px` 的小字——有氛围但毫无知识推演，沦为空洞的心灵鸡汤屏保！
> 
> **真正的爆款准则（以 64 万赞《熵》为标尺）：「每一个画面特效，都是在纯黑/纯净空间里完成一次肉眼可见的科学推演（Visual Proof）」！**

## 一、 四大核心铁律（防 PPT + 防鸡汤 + 防空洞屏保）

### 铁律 1：【剧本内核锁】一集只讲透 1 个底层定律/机制，严禁“散装例子凑鸡汤”
- **错误做法（散装鸡汤）**：先定一个情绪口号（如“人生容错率很大”），然后把“空调26度、飞机偏航、DNA复制、人有两颗肾、45岁创业”这 5 个完全不同领域的例子像报菜名一样拼在一起。例子之间没有共同的数学/物理推导，观众看完只觉得是鸡汤。
- **正确做法（单一机制一竿子捅到底）**：
  - **每集只锁定 1 个核心科学定律、数学模型或底层机制**（如：热力学第二定律 $S = k \cdot \log W$、香农信息熵 $H = -\sum p \log p$、最优停止定律 $1/e$、负反馈控制环 PID、幂律分布等）。
  - 全片 4 个段落全部围绕这 **1 个机制的变量关系** 层层深挖：
    1. **现象起兴**：3 个日常现象指向同一个反直觉问题 ➔ 砸出本期唯一的**核心科学概念**；
    2. **微观推演**：用一个最直观的思想实验（如 100 枚硬币怎么翻、3 盏灯怎么选、信号怎么衰减）把背后的**数学算式或物理机制一步步推出来**；
    3. **投射人心**：把这个定律的变量（如 $W$、温度 $37.0^\circ\text{C}$、采样阈值 $37\%$）直接投射到人自身的生命、身体或一段关系上，解释为什么不干预就会滑向失控；
    4. **破局条件**：在定律公式里圈出那个**唯一能逆转结局的变量**（如圈出“孤立系统”里的 `孤立` 二字），给出具体的破局行动。

### 铁律 2：【视觉证明锁】拒绝“抒情屏保风景画”，每个动效都必须在推导变量与机制（Visual Proof）
- **错误做法（屏保风景画）**：文案在讲“50岁创业成功率是30岁的 1.8 倍”，画面却画“月亮下长出五棵树”；文案在讲“1° 偏差飞 3000 英里偏离 52.4 英里”，画面却只画一架小飞机在夕阳下飞，数字缩在角落——**删掉画面完全不影响听字，画面没有替观众完成任何推理**！
- **正确做法（用无框生成式图形把机制“算”出来、“演”出来）**：
  - **不要方框外壳，但必须有硬核的图形推导过程**！
  - 凡台词出现关键数字、比例或机制变化，画面中央必须用**具象的动态几何、粒子矩阵或物理实验**把它演出来：
    - 讲“100 枚硬币一半正一半反排法最多”：左边实打实画出 `10×10` 共 100 枚发光硬币实时翻转（底部计数 `100/100 ➔ 50/100`），随后右侧巨型数字滚出 `100,891,344... 种`，紧接着数百颗粒子从天而降堆积成一座发光的正态分布山峰（标注 `最乱 = 最常见` vs `全部正面 ≈ 7.9×10⁻³¹`）；
    - 讲“1° 偏差飞 3000 英里偏离 52.4 英里，靠高频微调抵达”：画面中央必须实打实画出一条基准航线、一条以 `1°` 张角越拉越开的红色发散射线（动态张开缺口标尺实时跳到 `52.4 MILES`），随后展示自动驾驶高频脉冲每偏离一点就立刻反向纠偏拉回靶心的折线收敛过程；
    - 讲“DNA 复制把 $10^{-5}$ 错误率压到 $10^{-9}$”：画面必须展示碱基序列高速配对、出现一颗红色错配碱基报警、校对酶滑过将其精准切除替换为正确金色碱基，同时画面主数字从 `1 / 100,000` 实时滚轮裂变为 `1 / 1,000,000,000`！

### 铁律 3：【排版主角锁】巨型文字、数字与公式直接入画当构图主角（Typography as Hero）
- **错误做法（无主字 + 底部小字幕复读）**：整张 1920×1080 画布上只有图案，关键数字只有 `18px~24px` 贴在角落，把所有句子都塞进屏幕最底下的小字幕条里。
- **正确做法（文字与数字本身就是画面的一半江山）**：
  - **严格字阶规范（直接悬浮在纯净虚空中，无背景框、带柔和光学辉光）**：
    - **核心概念单字 / 核心公式 / 极值大数字**：**`120px ~ 240px`**（如 4000 粒子聚合成的巨型汉字、居中的 `$S = k \cdot \log W$`、或占满半屏的超大数字）；
    - **画面主命题句 / 转折定断句**：**`56px ~ 88px` 高雅宋体/衬线体**（直接作为画面主视觉放在画面中央或左/右半屏，重点词染成暖金 `#F5D08A` 或直接用发光手绘金圈一笔圈住！）；
    - **推导辅助标注与上下标**：**`26px ~ 36px` 等宽体/无衬线体**（紧贴在被解释的图形、公式变量或峰值旁边，拉出极细引导线）；
    - **底部字幕**：无黑底框，悬浮于 `y = 880`，字号 `32px ~ 36px` 宋体，单行精炼短句。

### 铁律 4：【收尾实效锁】严禁万能鸡汤格言，必须以“破局变量 + 具体微行动”收尾
- **错误做法**：结尾写“路是一直走才长出来的”、“时间会给你答案”，或者“欢迎在评论区聊聊”。
- **正确做法**：
  - 先回到全片的核心公式/定律，圈出那个**人类可以主动干预的变量**（例如：因为只有“孤立系统”才会必然滑向混乱，所以破局点就是“打破孤立、输入能量做功”）；
  - 在画面上逐行点亮 **3 件今晚就能做的具体生活小事**（如 `✓ 今晚，扫一扫地` / `✓ 给那个人，多回一句话` / `✓ 把搁置的那件事，推进 10 分钟`）；
  - 最后定格在一句从本集定律直接生长出来的洞察短句上（如 `规则，不是秩序。在意，才是。`），干脆切黑。

## 二、 动手写代码前的「单页论证与视觉证明表（Visual Proof Spec）」门禁

在编写任何一期视频的 `script.md` 和 `engine.html` 之前，必须先明确回答以下 4 个问题（写进 `facts.json`）：

1. **本期唯一的硬核定律/数学模型是什么？**（写出公式或核心因果机制：输入变量 $X$ 如何通过机制 $M$ 决定输出 $Y$？）
2. **全片的 3~4 个核心数字，每一个在画面上怎么“推演/对比”出来？**
   - 严禁只写“屏幕显示 XX%”！必须写明：`从什么初始状态 ➔ 经过什么几何/粒子/矩阵变化 ➔ 推导出这个数字`。
3. **本期的「核心破局眼」是哪两个字？**（在什么边界条件下该定律失效或可被逆转？画面上如何用手绘发光金圈或反转动画将其点破？）
4. **静音盲测检验**：如果把底部字幕遮住、把声音关掉，只看画面上的 **「巨型主字 + 公式 + 图形动态推演 + 数字跳变」**，观众能不能 100% 看懂这期视频在讲什么科学定律、怎么推导的？如果看不懂（比如只看到一棵树、一条河、一个圆球），说明画成了空洞屏保，必须重设计！

## 三、 全局视听与工程质量底线

1. **零 UI 方框外壳 + 高密度生成式机制图**：
   - 画布保持 `80%+` 深邃纯净留白（无卡片外框、无顶部软件状态条、无底部黑底胶囊框）；
   - 但留白中央的图形必须是**高信息密度的动态推演系统**（像素采样点云聚散、矩阵翻转、粒子沙漏正态堆积、矢量角度与标尺动态张开、序列校对替换、文字失重脱落、手绘金圈圈选公式变量）。
2. **每 2.5~4 秒一次信息状态变化**：
   - 每个镜头内部必须包含明确的 **状态推进（State 1 初始态 ➔ State 2 变量介入/冲突 ➔ State 3 数据/结论落定）**，严禁一个镜头 10 秒钟只在那里原地慢速旋转或发光！
3. **配音、音效与无黑屏渲染**：
   - 本地 `Auk-TTS`（`http://127.0.0.1:7863/api`，`小林 52920896bd09` / `女主播 08482905d56e` / `烛灵儿 3528e1c71180`，`speed=1.0` 原生语速，剥离 `【】`）；
   - 每一次数字推导、矩阵翻转、圈选重点、状态反转 100% 绑定 [`音效_精选`](../../../音效_精选/音效索引.md) 对应音效，母带 `-14 LUFS`；
   - Playwright Chromium 强制携带 `--allow-file-access-from-files --disable-web-security --disable-gpu --disable-accelerated-2d-canvas --disable-gpu-compositing`，确保 100% 零黑屏。
